# Battlezone Holo Text Generator

Generates the ODFs, images, materials, sprite-sheet entries, and Lua placement blocks used for in-game holographic HUD text with the `MakeExplosion` method.

## Release Builds

Public application names are stable and versionless:

- Windows: `BZHoloTextGenerator.exe`
- Linux: `BZHoloTextGenerator`
- macOS: `BZHoloTextGenerator`

Release archives carry the version and platform, for example:

- `Battlezone98Redux_HoloTextGen-v2.1-windows.zip`
- `Battlezone98Redux_HoloTextGen-v2.1-linux.tar.gz`
- `Battlezone98Redux_HoloTextGen-v2.1-macos.tar.gz`

Official Windows releases use the shared Battlezone tool-suite identity:

```text
FileDescription: Battlezone Holo Text Generator
ProductName: Battlezone Modding Tools
CompanyName: GrizzlyOne95
OriginalFilename: BZHoloTextGenerator.exe
```

`FileVersion` and `ProductVersion` are derived from the canonical repository version.
